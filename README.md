# Бот расписания ВКБ51

Бот получает расписание группы с [сайта ДГТУ](https://edu.donstu.ru/WebApp/#/Rasp/Group/72244), проверяет его каждые 5 минут и присылает конкретные изменения: добавление, удаление, перенос, смену преподавателя или аудитории. В 08:00 по Москве присылает расписание на текущий день **картинкой-карточкой**, а по понедельникам — карточку текущей недели. Telegram и ВКонтакте можно включить одновременно. На карточках лекции зелёные, практики жёлто-оранжевые, лабораторные фиолетовые; аудитория выделена справа от предмета. Свободные пары между занятиями показаны как окна. Если отправить картинку не удалось, бот попробует прислать расписание текстом.

Примеры: [карточка дня](preview.png), [неделя](preview_week.png), [день с окном](preview_windows.png).

Если расписание изменится после отправки карточки, бот пришлёт текстовое описание изменений и заменит картинку в уже отправленном сообщении. Если сервис запретит редактирование старого сообщения, бот отправит новую актуальную карточку. Для редактирования бот сохраняет ID отправленных карточек в `data/state.json`. После установки этой версии вместо старой бот один раз пришлёт новую карточку за текущий день, чтобы начать отслеживать её ID.

Используется `https://edu.donstu.ru/api/Rasp?idGroup=72244`. Ссылка с `idStudent=NaN` не подходит: `NaN` не является ID студента. Группа на сайте называется **ВКБ51**. Бот каждый день перепроверяет её числовой ID через поиск ДГТУ.

Первый успешный запрос создаёт исходный снимок без оповещения о старых занятиях. Затем бот сравнивает будущие и текущие занятия. Состояние и очередь отправки сохраняются в `data/state.json`; после перезапуска уведомления не теряются. Если API временно недоступен или неожиданно отдаёт пустой список, прежний снимок сохраняется. Запросы и отправка выполняются только когда процесс запущен; для круглосуточной работы нужен постоянно работающий компьютер или сервер.

## Быстрый запуск

Нужен Python 3.11+.

1. Скопируйте `.env.example` в `.env` рядом с `bot.py`.
2. Настройте хотя бы один канал по инструкциям ниже. Для обоих заполните оба блока.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Проверьте доступность расписания: `python bot.py --preview`. `python bot.py --preview-card` сохранит карточку дня в `data/preview.png`, а `python bot.py --preview-week` — карточку недели в `data/preview_week.png`.
5. Запустите бота: `python bot.py`. Оставьте окно открытым.

В PowerShell команды выглядят так:

```powershell
Copy-Item .env.example .env
notepad .env
python -m pip install -r requirements.txt
python bot.py --preview
python bot.py
```

Для фонового запуска с Docker: `docker compose up -d --build`. Остановка: `docker compose down`. Данные сохраняются в `data/`. Файл `.env` содержит секреты: не выкладывайте его в открытый доступ.

## Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. Запишите выданный токен в `TELEGRAM_BOT_TOKEN`.
3. Замените пример `TELEGRAM_PAIR_CODE` на случайный секретный код (например, длинную комбинацию букв и цифр).
4. После запуска откройте своего бота и отправьте ему `/start ВАШ_КОД`. Он запомнит этот личный чат и пришлёт расписание на сегодня.

После сопряжения бот показывает **постоянные кнопки вместо обычной клавиатуры**: «Сегодня», «Завтра», «◀️ Неделя», «Неделя ▶️», «Эта неделя». Стрелки листают от открытой недели, поэтому можно пройти несколько недель назад и затем вернуться вперёд. Бот хранит выбранную неделю после перезапуска. Предел прокрутки — первая и последняя недели в доступном ответе ДГТУ; за этим пределом бот скажет, что данных нет. У уже привязанного чата кнопки появятся сразу после перезапуска обновлённого бота.

Старые команды также работают: `/today` и `/tomorrow` возвращают карточку дня, `/week` и `/nextweek` — карточку текущей или следующей недели. Для текстового варианта используйте `/today_text` и `/tomorrow_text`. Если ID чата уже известен, можно указать `TELEGRAM_CHAT_ID` вместо кода сопряжения. Чтобы сменить привязанный чат, остановите бота, удалите поле `telegram_chat_id` из `data/state.json` и запустите снова.

## ВКонтакте

1. Создайте сообщество ВКонтакте, включите сообщения сообщества и выдайте токен сообщества с правом отправлять сообщения.
2. Напишите сообществу личное сообщение со своего аккаунта, чтобы оно могло отвечать вам.
3. Укажите токен в `VK_COMMUNITY_TOKEN`, а свой числовой ID ВКонтакте (например, `123456` из адреса `vk.com/id123456`) в `VK_PEER_ID`.

ВКонтакте бот отправляет ежедневную и еженедельную карточки, а также изменения в личные сообщения. Навигационные кнопки реализованы в Telegram. Для карточки бот загружает фото через API ВКонтакте; сообщения сообщества должны быть включены.

## Прокси

Для Telegram добавьте в `.env` строку `TELEGRAM_PROXY_URL=http://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_HTTP`. Используйте HTTP-порт из панели прокси. Адрес HTTP-прокси из панели можно вставить и без `http://`: бот добавит его сам. При желании можно выбрать SOCKS5-порт и формат `socks5h://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_SOCKS5`. Для адреса из вашего скриншота подходят оба варианта; заполните **один**. Если в логине или пароле есть `@`, `:`, `/` или `#`, замените эти символы на URL-коды (`%40`, `%3A`, `%2F`, `%23`).

`TELEGRAM_PROXY_URL` направляет через прокси только Telegram. Для всех запросов используйте `PROXY_URL`; отдельные настройки `DONSTU_PROXY_URL` и `VK_PROXY_URL` перекрывают общую для соответствующего сервиса. Команда `python bot.py --doctor` покажет, какой тип прокси выбран и проходит ли проверка Telegram API, не печатая логин и пароль. Не присылайте заполненный `.env` и не публикуйте его.

## Настройки

| Поле | Значение |
| --- | --- |
| `GROUP_NAME` | `ВКБ51` |
| `GROUP_ID` | запасной ID `72244`, найденный 24.09.2026 |
| `DAILY_TIME` | время ежедневной отправки по Москве, `08:00` |
| `CHECK_INTERVAL_SECONDS` | интервал проверки в секундах, минимум 60 |
| `STATE_FILE` | путь к файлу состояния, по умолчанию `data/state.json` |

Время отправки проверяется при очередном опросе, поэтому возможна задержка до одного интервала проверки. Если процесс был выключен утром, расписание за текущий день придёт после запуска. Недельная карточка отправляется по понедельникам после `DAILY_TIME`; её также можно получить командой `/week`. При ошибке отправки сообщение остаётся в очереди и будет повторено. Сетка пар взята из расписания ВКБ51: 08:30–10:05, 10:15–11:50, 12:00–13:35, 14:15–15:50, 16:00–17:35, 17:45–19:20, 19:30–21:05. Окна отмечаются только между первой и последней занятой парой дня.

## Проверка

```powershell
python -m unittest -v test_bot.py
python bot.py --preview
python bot.py --preview-card
python bot.py --preview-week
python bot.py --doctor
```

При обновлении уже работающего бота сохраните свои `.env` и `data/state.json`, замените файлы программы, установите зависимости заново и перезапустите процесс. Не запускайте две копии одновременно: они будут конкурировать за команды Telegram.

Если бот не ответил на `/start КОД`, откройте PowerShell **в папке с `bot.py`** и выполните `python bot.py --doctor`. Он покажет, найден ли `.env`, действителен ли токен Telegram, не включён ли webhook и сохранился ли чат. Секреты команда не печатает. Если окно `python bot.py` сразу закрывается, запустите ту же команду из PowerShell и прочитайте сообщение об ошибке. Команду сопряжения нужно отправлять боту в личном чате с косой чертой, одним пробелом и кодом из `.env`.
