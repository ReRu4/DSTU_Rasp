# Бот расписания ДГТУ

Бот проверяет расписание ДГТУ каждые пять минут и присылает изменения, ежедневную карточку и карточку недели по понедельникам. Каждый подписчик Telegram выбирает свою группу, время отправки по Москве, вид недельной карточки и сезонное оформление через кнопку **⚙️ Настройки**. ВКонтакте работает как отдельный подписчик с параметрами из `.env`; кнопки и личные настройки доступны в Telegram.

На карточках лекции зелёные, практики жёлто-оранжевые, лабораторные фиолетовые. Аудитория выделена справа от названия предмета. Совпадающие по времени занятия показаны отдельно; свободные пары между занятиями отмечены как **ОКНО**. Осенняя тема действует для дат сентября–ноября, если она включена. Выключение сезонной темы оставляет классическую палитру для всех дат. Примеры сохранены из данных расписания с искусственным изменением для красной подсветки.

Если расписание изменилось **сегодня**, бот присылает текст об изменении и обновляет уже отправленную карточку. Если Telegram или ВКонтакте не дают отредактировать старое сообщение, бот отправляет новую карточку. Если изменился **будущий день**, бот присылает текст с тем, что добавлено, удалено или исправлено. Кнопка «🗓 Показать изменения» в Telegram создаёт по одной недельной карточке на каждую затронутую неделю. Изменения и удаления на этих карточках выделены красным. Для ВКонтакте уведомление остаётся текстовым.

Первый успешный запрос создаёт исходный снимок без оповещения о старых парах. Состояние, личные настройки и очередь уведомлений хранятся в `data/state.json`. После перезапуска они сохраняются. При временной ошибке API бот продолжает использовать последний снимок.

## Быстрый запуск

Нужен Python 3.11+ и постоянно работающий компьютер или сервер.

```powershell
Copy-Item .env.example .env
notepad .env
python -m pip install -r requirements.txt
python bot.py --doctor
python bot.py
```

В `.env` укажите токен Telegram и свой секретный `TELEGRAM_PAIR_CODE`. Создайте бота через [@BotFather](https://t.me/BotFather), затем напишите ему в личном чате `/start ВАШ_КОД`. Бот сразу отвечает, загружает группу и присылает карточку дня. Один код может подключить несколько чатов; у каждого будут свои настройки. Если нужен только один чат, поставьте `ALLOW_MULTIPLE_USERS=false`. Вместо кода можно заранее задать числовой `TELEGRAM_CHAT_ID`.

Кнопки Telegram находятся вместо клавиатуры: **Сегодня**, **Завтра**, **◀️ Неделя**, **Эта неделя**, **Неделя ▶️**, **📝 Текст**, **⚙️ Настройки**. Стрелки листают недели, в том числе прошедшие, пока они доступны в ответе ДГТУ. «📝 Текст» открывает обзор недели со встроенными кнопками дней. Команды `/today`, `/tomorrow`, `/week`, `/text` и `/settings` тоже работают.

В **⚙️ Настройки** нажмите нужную строку:

1. **Группа** — отправьте название как на сайте ДГТУ, например `ВКБ51`. Бот проверит группу и сразу покажет её расписание. Изменение затронет только ваш чат.
2. **Время** — отправьте `ЧЧ:ММ`, например `19:30`. Часовой пояс — Москва.
3. **Неделя** — переключает горизонтальный и вертикальный виды.
4. **Сезонная тема** — включает или выключает оформление времени года.
5. **Пример ↔️ / ↕️** — присылает обе версии недельной карточки с вашей группой без смены выбранного формата.

При настройке ВКонтакте укажите `VK_COMMUNITY_TOKEN` и `VK_PEER_ID`, включите сообщения сообщества и напишите ему один раз. ВКонтакте получает те же уведомления и карточки для группы, времени и оформления из `.env`.

Для фонового запуска используйте `docker compose up -d --build`; остановка — `docker compose down`. Данные остаются в `data/`. Не запускайте две копии бота с одним токеном Telegram одновременно.

## Параметры `.env`

| Переменная | Для чего |
| --- | --- |
| `GROUP_NAME`, `GROUP_ID` | Исходная группа и запасной ID для новых подписчиков и ВКонтакте |
| `DAILY_TIME` | Исходное время отправки, например `08:00` |
| `WEEK_LAYOUT` | `horizontal` или `vertical`; исходный вид недели |
| `SEASONAL_THEME` | `true` или `false`; исходное сезонное оформление |
| `ALLOW_MULTIPLE_USERS` | `true` разрешает несколько Telegram-подписчиков по коду |
| `CHECK_INTERVAL_SECONDS` | Интервал проверки ДГТУ, минимум 60 секунд |
| `STATE_FILE` | Файл состояния, по умолчанию `data/state.json` |

Параметры `.env` задают значения **для новых подписчиков** и ВКонтакте. Изменения через «⚙️ Настройки» сохраняются отдельно для существующих Telegram-подписчиков. Отправка по выбранному времени проверяется в цикле обработки сообщений, поэтому не зависит от пятиминутной проверки сайта. Если бот был выключен в нужный момент, карточка текущего дня будет отправлена после запуска.

## Прокси и диагностика

Для Telegram можно задать `TELEGRAM_PROXY_URL=http://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_HTTP` или `socks5h://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_SOCKS5`. Для всех запросов есть `PROXY_URL`; отдельные `DONSTU_PROXY_URL` и `VK_PROXY_URL` перекрывают его для соответствующих сервисов. Спецсимволы в логине и пароле нужно URL-кодировать.

`python bot.py --doctor` покажет, найден ли `.env`, доступен ли Telegram, не включён ли webhook, сколько подписчиков и расписаний загружено. Секреты команда не печатает. Ссылка `idStudent=NaN` не подходит для группы; бот ищет её числовой ID и использует `api/Rasp?idGroup=...`.

Для проверки карточек: `python bot.py --preview-card`, `python bot.py --preview-horizontal` и `python bot.py --preview-vertical`. Для тестов: `python -m unittest -v test_bot.py test_multibot.py`.

При обновлении сохраните свои `.env` и `data/state.json`, замените файлы программы, установите зависимости и перезапустите бота. Старая привязка чата и история расписания автоматически переносятся в личный профиль.
