# Бот расписания ДГТУ

Бот проверяет расписание ДГТУ каждые пять минут и присылает изменения, ежедневную карточку и карточку недели по понедельникам. По ссылке на Telegram-бота может подключиться любой пользователь: после **Start** он вводит свою группу и получает отдельное расписание и личные настройки. Время отправки по Москве, вид недельной карточки, сезонное оформление и виды уведомлений у каждого свои. ВКонтакте работает как отдельный подписчик с параметрами из `.env`; кнопки и личные настройки доступны в Telegram.

На карточках лекции зелёные, практики жёлто-оранжевые, лабораторные фиолетовые. В горизонтальной сетке аудитория стоит справа под названием. Два занятия в одно время разделяются на две части с отдельными преподавателями и аудиториями; три и более идут друг за другом. Свободные пары отмечены как **ОКНО**, пустой день — «Нет занятий», воскресенье — «Выходной». Если весь день заняла военная кафедра, она показана одним блоком. Осенняя тема действует для дат сентября–ноября, если она включена. В примерах изменений использованы демонстрационные занятия и аудитории с буквами.

Если расписание изменилось **сегодня**, бот присылает текст об изменении и обновляет уже отправленную карточку. Если Telegram или ВКонтакте не дают отредактировать старое сообщение, бот отправляет новую карточку. Если изменился **будущий день**, бот присылает текст с тем, что добавлено, удалено или исправлено. Кнопка «🗓 Показать изменения» в Telegram создаёт по одной недельной карточке на каждую затронутую неделю. На ней добавление отмечено жёлтой плашкой справа сверху, изменение — голубой. При смене аудитории есть плашка «Аудитория изменена» и выделена новая аудитория. Удалённая пара залита красным и помечена «Удалено». Для ВКонтакте уведомление остаётся текстовым. Бот сравнивает сами занятия: замена служебного кода в API без изменения расписания больше не вызывает уведомление.

Первый успешный запрос создаёт исходный снимок без оповещения о старых парах. Состояние, личные настройки и очередь уведомлений хранятся в `data/state.json`. После перезапуска они сохраняются. При временной ошибке API бот продолжает использовать последний снимок.

## Быстрый запуск

Нужен Python 3.11+ и постоянно работающий компьютер или сервер.

```powershell
Copy-Item .env.example .env
notepad .env
python -m pip install -r requirements.txt
python bot.py --doctor
python bot.py
```

В `.env` укажите токен бота, созданного через [@BotFather](https://t.me/BotFather), и `TELEGRAM_ACCESS=public`. Поставьте `ALLOW_MULTIPLE_USERS=true`. Команда `python bot.py --doctor` покажет ссылку вида `https://t.me/имя_бота`: отправьте её другим людям. Каждый открывает бота в личном чате, нажимает **Start**, пишет свою группу как на сайте ДГТУ и получает карточку дня. После этого он может открыть **⚙️ Настройки** и выбрать удобные параметры. Уже подключённые пользователи сохраняют свои группы и настройки при обновлении.

Если требуется закрытый бот, поставьте `TELEGRAM_ACCESS=code` и задайте `TELEGRAM_PAIR_CODE`. Тогда новый пользователь подключается командой `/start ВАШ_КОД`. Для единственного чата можно использовать `ALLOW_MULTIPLE_USERS=false` или заранее указать числовой `TELEGRAM_CHAT_ID`.

После выбора группы кнопки Telegram находятся вместо клавиатуры: **Сегодня**, **Завтра**, **◀️ Неделя**, **Эта неделя**, **Неделя ▶️**, **📝 Текст**, **⚙️ Настройки**. Стрелки листают недели, в том числе прошедшие, пока они доступны в ответе ДГТУ. «📝 Текст» открывает обзор недели со встроенными кнопками дней. Команды `/today`, `/tomorrow`, `/week`, `/text` и `/settings` тоже работают.

В **⚙️ Настройки** нажмите нужную строку:

1. **Группа** — отправьте название как на сайте ДГТУ, например `ВКБ51`. Бот проверит группу и сразу покажет её расписание. Изменение затронет только ваш чат.
2. **Время** — отправьте `ЧЧ:ММ`, например `19:30`. Часовой пояс — Москва.
3. **Неделя** — открывает выбор из горизонтальной сетки, вертикальной недели и чистого списка. У каждого вида есть кнопка «Пример» с вашей группой.
4. **Сезонная тема** — включает или выключает оформление времени года.
5. **Уведомления** — выберите, на что реагировать: добавление, удаление, дату и время, аудиторию, преподавателя, предмет, подгруппу, замену, тему и ссылку. Можно включить или выключить все виды сразу. Выбор сохраняется отдельно для каждого Telegram-чата. По умолчанию включены все виды.

Отключённый вид изменений не создаёт текстовое уведомление и не подсвечивается на карточке изменений. Ежедневная отправка и обновление уже присланных карточек продолжают работать. Для ВКонтакте виды уведомлений задаются в `.env` через `VK_ALERT_TYPES`; ложные уведомления от смены кодов занятий также устранены.

При настройке ВКонтакте укажите `VK_COMMUNITY_TOKEN` и `VK_PEER_ID`, включите сообщения сообщества и напишите ему один раз. ВКонтакте получает те же уведомления и карточки для группы, времени и оформления из `.env`.

Для фонового запуска используйте `docker compose up -d --build`; остановка — `docker compose down`. Данные остаются в `data/`. Не запускайте две копии бота с одним токеном Telegram одновременно.

## Параметры `.env`

| Переменная | Для чего |
| --- | --- |
| `GROUP_NAME`, `GROUP_ID` | Исходная группа и запасной ID для режима доступа по коду и ВКонтакте |
| `TELEGRAM_ACCESS` | `public` для подключения по ссылке или `code` для доступа по коду |
| `TELEGRAM_PAIR_CODE` | Секретный код, нужен только при `TELEGRAM_ACCESS=code` |
| `ALLOW_MULTIPLE_USERS` | `true` разрешает отдельные профили нескольким людям |
| `DAILY_TIME` | Исходное время отправки, например `08:00` |
| `WEEK_LAYOUT` | `horizontal`, `vertical` или `list`; исходный вид недели |
| `SEASONAL_THEME` | `true` или `false`; исходное сезонное оформление |
| `CHECK_INTERVAL_SECONDS` | Интервал проверки ДГТУ, минимум 60 секунд |
| `STATE_FILE` | Файл состояния, по умолчанию `data/state.json` |
| `VK_ALERT_TYPES` | Виды уведомлений ВК через запятую: `added`, `removed`, `time`, `room`, `teacher`, `subject`, `subgroup`, `replacement`, `other`. Значения `all` и `none` включают или выключают все виды; по умолчанию `all` |

Параметры `.env` задают значения **для новых подписчиков** и ВКонтакте. Изменения через «⚙️ Настройки» сохраняются отдельно для существующих Telegram-подписчиков. Отправка по выбранному времени проверяется в цикле обработки сообщений, поэтому не зависит от пятиминутной проверки сайта. Если бот был выключен в нужный момент, карточка текущего дня будет отправлена после запуска.

## Прокси и диагностика

Для Telegram можно задать `TELEGRAM_PROXY_URL=http://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_HTTP` или `socks5h://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_SOCKS5`. Для всех запросов есть `PROXY_URL`; отдельные `DONSTU_PROXY_URL` и `VK_PROXY_URL` перекрывают его для соответствующих сервисов. Спецсимволы в логине и пароле нужно URL-кодировать.

`python bot.py --doctor` покажет ссылку на бота, режим доступа, доступность Telegram, состояние webhook и число подписчиков. Секреты команда не печатает. Ссылка `idStudent=NaN` не подходит для группы; бот ищет её числовой ID и использует `api/Rasp?idGroup=...`.

Для проверки карточек: `python bot.py --preview-card`, `python bot.py --preview-horizontal`, `python bot.py --preview-vertical` и `python bot.py --preview-list`. Для тестов: `python -m unittest -v test_bot.py test_multibot.py`.

При обновлении сохраните свои `.env` и `data/state.json`, замените файлы программы, установите зависимости и перезапустите бота. Старая привязка чата и история расписания автоматически переносятся в личный профиль.
