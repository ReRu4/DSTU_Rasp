# Бот расписания ДГТУ

Бот проверяет расписание ДГТУ каждые пять минут и присылает изменения, ежедневную карточку и карточку недели по понедельникам. По ссылке на Telegram-бота может подключиться любой пользователь: после **Start** он вводит свою группу и получает отдельное расписание и личные настройки. Время отправки по Москве, вид недельной карточки, сезонное оформление и виды уведомлений у каждого свои. ВКонтакте работает как отдельный подписчик с параметрами из `.env`; кнопки и личные настройки доступны в Telegram.

На карточках лекции зелёные, практики жёлто-оранжевые, лабораторные фиолетовые. Недельные карточки и текстовый обзор показывают понедельник–субботу; воскресенье скрыто. В горизонтальной сетке шесть дней занимают всю доступную ширину, аудитория стоит справа под названием. Два занятия в одно время разделяются на две части с отдельными преподавателями и аудиториями; три и более идут друг за другом. Свободные пары отмечены как **ОКНО**, пустой день — «Нет занятий». Если весь день заняла военная кафедра, она показана одним блоком. Осенняя тема действует для дат сентября–ноября, если она включена. В примерах изменений использованы демонстрационные занятия и аудитории с буквами.

При изменениях бот присылает текст с тем, что добавлено, удалено или исправлено. По умолчанию новые картинки автоматически не отправляются: в Telegram есть кнопка «🗓 Показать расписание». Уже присланные обычные карточки дня, недели и месяца обновляются при изменениях, пока сообщение можно редактировать; архивные карточки изменений сохраняют свой снимок. Если включить в настройках **Карточки при изменениях**, вслед за отчётом придут новые недельные карточки для каждой затронутой группы и недели. Добавление отмечено жёлтой плашкой справа сверху, изменение — голубой. При смене аудитории есть плашка «Аудитория изменена» и выделена новая аудитория. Удалённая пара залита красным и помечена «Удалено». Бот сравнивает сами занятия: замена служебного кода в API без изменения расписания не вызывает уведомление.

Месячный календарь показывает короткие названия, время, аудитории и окна с понедельника по субботу. Все параллельные записи сохраняются; высота недели зависит от числа занятий. Военная кафедра без изменений показана одним блоком. Пустой день подписан «Нет записей»: отсутствие записей в API само по себе не подтверждает выходной или полноту публикации.

Первый успешный запрос создаёт исходный снимок без оповещения о старых парах. Состояние, личные настройки и очередь уведомлений хранятся в `data/state.json`. После перезапуска они сохраняются. При временной ошибке API бот продолжает использовать последний снимок.

В подписях к карточкам, текстовом расписании и настройках отображается время последней успешной проверки ДГТУ по Москве. Это время получения данных, даже если сами пары не изменились. Если обновление не удалось, бот явно пишет, что показывает сохранённую версию, и указывает время её последней успешной проверки. Ошибка сети или неожиданный пустой ответ не стирают ранее полученное расписание. Для старых сохранённых данных без метки времени отображается «время проверки неизвестно» до следующего успешного запроса; если снимка ещё нет, бот сообщает, что расписание не загружено.

Кнопка **🔄 Обновить** доступна в настройках и под предупреждением о сбое в расписании. Под расписанием она проверяет группу именно этой карточки; в настройках — все включённые группы пользователя. Снимки других подписчиков тех же групп тоже обновляются, сохраняя личные настройки каждого. Повторный запрос по той же группе доступен через 30 секунд после предыдущей попытки. При сбое можно продолжать смотреть сохранённое расписание; автоматические проверки продолжаются с обычным интервалом.

Метка в сообщении соответствует последнему успешному получению снимка на момент формирования этого сообщения. Уже отправленные сообщения не переписываются каждые пять минут только ради метки времени: новый статус виден при открытии расписания или нажатии «Обновить». Карточки из уведомлений об изменениях сохраняют время своего исторического снимка.

## Быстрый запуск

Нужен Python 3.11+ и постоянно работающий компьютер или сервер.

```powershell
Copy-Item .env.example .env
notepad .env
python -m pip install -r requirements.txt
python bot.py --doctor
python bot.py
```

В `.env` укажите токен бота, созданного через [@BotFather](https://t.me/BotFather), и `TELEGRAM_ACCESS=public`. Поставьте `ALLOW_MULTIPLE_USERS=true`. Команда `python bot.py --doctor` покажет ссылку вида `https://t.me/имя_бота`: отправьте её другим людям. Каждый открывает бота в личном чате, нажимает **Start**, пишет свою группу как на сайте ДГТУ и получает карточку дня. После этого он может открыть **⚙️ Настройки** и выбрать удобные параметры. Уже подключённые пользователи сохраняют свои группы и настройки при обновлении.

Если требуется закрытый бот, поставьте `TELEGRAM_ACCESS=code` и задайте `TELEGRAM_PAIR_CODE`. Тогда новый пользователь подключается командой `/start ВАШ_КОД`. Для единственного чата можно использовать `ALLOW_MULTIPLE_USERS=false` или заранее указать числовой `TELEGRAM_CHAT_ID`.

После выбора группы внизу Telegram четыре постоянные кнопки: **Сегодня**, **Неделя**, **Месяц**, **Настройки**. Под расписанием — стрелки для перелистывания и **Сегодня** для дня или **Выбрать день** для недели/месяца. Календарь дат появляется по запросу. Навигация редактирует текущее сообщение; если Telegram уже не позволяет его редактировать, бот отправит новое. Прошедшие даты тоже можно открыть, но данные доступны только из сохранённого снимка ДГТУ. При нескольких группах под расписанием появляется дополнительный выбор группы. Команды `/today`, `/tomorrow`, `/week`, `/month`, `/text` и `/settings` сохраняются.

В **⚙️ Настройки** нажмите нужную строку:

1. **Группа** — отправьте название как на сайте ДГТУ, например `ВКБ51`. Бот проверит группу и сразу покажет её расписание. Изменение затронет только ваш чат.
2. **Время** — отправьте `ЧЧ:ММ`, например `19:30`. Часовой пояс — Москва.
3. **Неделя** — открывает выбор из горизонтальной сетки, вертикальной недели и чистого списка. У каждого вида есть кнопка «Пример» с вашей группой.
4. **Сезонная тема** — включает или выключает оформление времени года.
5. **Уведомления** — выберите, на что реагировать: добавление, удаление, дату и время, аудиторию, преподавателя, предмет, подгруппу, замену, тему и ссылку. Можно включить или выключить все виды сразу. Выбор сохраняется отдельно для каждого Telegram-чата. По умолчанию включены все виды.
6. **Формат дня и недели** — картинка или текст. Месяц остаётся календарём-картинкой, примеры оформления также показываются картинками.
7. **Несколько групп** — по умолчанию выключено. Включите и добавьте до десяти дополнительных групп; их можно удалить или временно выключить весь режим. Для просмотра выберите группу под расписанием. Ежедневная рассылка и понедельничная неделя остаются для основной группы.
8. **Карточки при изменениях** — по умолчанию выключено. Настройка действует и при одной группе, и при нескольких: только текст с кнопкой просмотра либо текст и новые карточки затронутых недель.

Отключённый вид изменений не создаёт текстовое уведомление и не подсвечивается на карточке изменений. Ежедневная отправка продолжает работать. Изменения нескольких групп за одну проверку собираются в общий отчёт, разделённый по группам. Длинный отчёт может быть разбит на несколько сообщений из-за лимита Telegram. Одинаковая группа у разных подписчиков запрашивается один раз за цикл; настройки и история каждого пользователя сохраняются отдельно. Для ВКонтакте виды уведомлений задаются в `.env` через `VK_ALERT_TYPES`.

При настройке ВКонтакте укажите `VK_COMMUNITY_TOKEN` и `VK_PEER_ID`, включите сообщения сообщества и напишите ему один раз. ВКонтакте получает те же уведомления и карточки для группы, времени и оформления из `.env`.

Для фонового запуска используйте `docker compose up -d --build`; остановка — `docker compose down`. Данные остаются в `data/`. Не запускайте две копии бота с одним токеном Telegram одновременно.

## Параметры `.env`

| Переменная | Для чего |
| --- | --- |
| `GROUP_NAME`, `GROUP_ID` | Исходная группа и запасной ID для режима доступа по коду и ВКонтакте |
| `TELEGRAM_ACCESS` | `public` для подключения по ссылке или `code` для доступа по коду |
| `TELEGRAM_PAIR_CODE` | Секретный код, нужен только при `TELEGRAM_ACCESS=code` |
| `ALLOW_MULTIPLE_USERS` | `true` разрешает отдельные профили нескольким людям |
| `DAILY_TIME` | Исходное время отправки, например `08:00` |
| `WEEK_LAYOUT` | `horizontal`, `vertical` или `list`; исходный вид недели |
| `SEASONAL_THEME` | `true` или `false`; исходное сезонное оформление |
| `CHECK_INTERVAL_SECONDS` | Интервал проверки ДГТУ, минимум 60 секунд |
| `STATE_FILE` | Файл состояния, по умолчанию `data/state.json` |
| `VK_ALERT_TYPES` | Виды уведомлений ВК через запятую: `added`, `removed`, `time`, `room`, `teacher`, `subject`, `subgroup`, `replacement`, `other`. Значения `all` и `none` включают или выключают все виды; по умолчанию `all` |

Параметры `.env` задают значения **для новых подписчиков** и ВКонтакте. Изменения через «⚙️ Настройки» сохраняются отдельно для существующих Telegram-подписчиков. Отправка по выбранному времени проверяется в цикле обработки сообщений, поэтому не зависит от пятиминутной проверки сайта. Если бот был выключен в нужный момент, карточка текущего дня будет отправлена после запуска.

## Прокси и диагностика

Для Telegram можно задать `TELEGRAM_PROXY_URL=http://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_HTTP` или `socks5h://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ_SOCKS5`. Для всех запросов есть `PROXY_URL`; отдельные `DONSTU_PROXY_URL` и `VK_PROXY_URL` перекрывают его для соответствующих сервисов. Спецсимволы в логине и пароле нужно URL-кодировать.

`python bot.py --doctor` покажет ссылку на бота, режим доступа, доступность Telegram, состояние webhook и число подписчиков. Секреты команда не печатает. Ссылка `idStudent=NaN` не подходит для группы; бот ищет её числовой ID и использует `api/Rasp?idGroup=...`.

Для проверки карточек: `python bot.py --preview-card`, `python bot.py --preview-horizontal`, `python bot.py --preview-vertical` и `python bot.py --preview-list`. Для всех тестов: `python -m unittest discover -v`.

При обновлении сохраните свои `.env` и `data/state.json`, замените файлы программы, установите зависимости и перезапустите бота. Старая привязка чата и история расписания автоматически переносятся в личный профиль.

## Обновление сервера и анонс

После получения изменений запустите `docker compose up -d --build` из каталога проекта либо перезапустите свой процесс `python bot.py`. Сохраните прежние `.env` и `data/`: они содержат настройки и подписчиков, в GitHub не отправляются. Compose подключает `./data` как постоянный том.

При первом запуске этой версии ранее подключённым пользователям Telegram отправляется одно сообщение о месячном календаре, новых кнопках, свежести и нескольких группах. Успешная отправка отмечается в профиле полем `last_release_notified`; обычный перезапуск не повторяет анонс. При ошибке доставки сообщение остаётся в очереди для повторной попытки. Новые пользователи сразу получают новый интерфейс без отдельного анонса. Текст и версия анонса заданы в `app_bot.py`. Обновление файлов или push в GitHub сами по себе ничего пользователям не отправляют.
